# Changesets

This folder holds [changesets](https://github.com/changesets/changesets): one Markdown file per
unreleased change, describing which packages it affects and how much to bump them.

Create one with `pnpm changeset` for **any** change worth releasing — to the npm package or to a
plugin. Both are versioned from here; see
[docs/how-to.md#release-a-new-version](../docs/how-to.md#release-a-new-version).
