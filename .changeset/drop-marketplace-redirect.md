The `arnaud-zg` Claude Code marketplace is gone from this repository. It only redirected to
[arnaud-zg/skills](https://github.com/arnaud-zg/skills) since 0.3.2. If you still have it, switch:

```sh
/plugin marketplace remove arnaud-zg
/plugin marketplace add arnaud-zg/skills
/plugin install arnaud-zg@arnaud-zg-skills
```

Nothing in the npm package changes.
